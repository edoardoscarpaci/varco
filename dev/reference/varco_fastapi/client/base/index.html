    varco_fastapi.client.base ¶

    varco_fastapi.client.base¶

    ClientProfile, AsyncVarcoClient[R], and _VarcoClientMeta metaclass.

    Architecture overview::

    ClientProfile        — reusable bundle of middleware / TLS / timeout config
ClientConfigurator   — per-service URL / proxy / env config (in configurator.py)
_VarcoClientMeta     — metaclass: generates typed CRUD methods at class-definition
AsyncVarcoClient[R]  — concrete httpx-backed client; metaclass applies to it
SyncVarcoClient      — sync wrapper (in sync.py), created via .sync property

    The metaclass pattern mirrors AsyncService's __init_subclass__ approach for resolving generic type parameters, but uses __new__ (metaclass) because we need to inject methods, not just record metadata.

    metaclass method generation over @overload stubs

    ✅ Methods exist at runtime — no stubs required for basic usage ✅ IDE stubs can still be generated by StubGenerator for autocomplete ✅ Same router introspection used by build_router() — single source of truth ✅ Methods generated once per class — no per-instance overhead ❌ Metaclass adds complexity — mitigated by confining it to _VarcoClientMeta

    frozen ClientProfile over mutable client config

    ✅ Safe to share across multiple client instances and services ✅ with_middleware() / with_timeout() return new profiles (immutable builders) ✅ Factory methods (production, development, from_env) cover 90% of use cases ❌ Appending middleware requires with_middleware() — no in-place mutation

    ✅ ClientProfile is frozen — safe to share across threads.

    ✅ _VarcoClientMeta is called once at class-definition; no shared state.

    Async safety: ✅ AsyncVarcoClient creates a fresh httpx.AsyncClient per instance; no shared mutable state between concurrent callers.

    ClientProfile dataclass ¶

    ClientProfile(
    middleware: tuple[AbstractClientMiddleware, ...] = (),
    trust_store: TrustStore | None = None,
    timeout: float = 30.0,
)

    Reusable bundle of client middleware, TLS trust store, and timeout.

    Shared across multiple AsyncVarcoClient instances — frozen so it is safe to share across threads and services.

    Three factory methods cover the common cases:

    1. production() — OTel tracing + JWT auth + correlation + retry.
    2. development() — logging + correlation only (no auth / TLS).
    3. from_env() — reads VARCO_CLIENT_TIMEOUT, VARCO_CLIENT_RETRY_MAX, VARCO_CLIENT_RETRY_DELAY, VARCO_CLIENT_OTEL_ENABLED.

    Immutable builders::

    prod = ClientProfile.production(authority=my_authority)
with_extra = prod.with_middleware(HeadersMiddleware({"X-Service": "api"}))
fast = prod.with_timeout(5.0)

    Parameters:

    Name Type Description Default
    middleware tuple[AbstractClientMiddleware, ...]

    Tuple of AbstractClientMiddleware instances applied in order.

    		 ()
    trust_store TrustStore | None

    TrustStore for TLS CA / mTLS config. None = system CAs.

    		 None
    timeout float

    Default request timeout in seconds.

    		 30.0

    Thread safety: ✅ frozen=True — safe to share across threads / services. Async safety: ✅ Pure data object; no I/O.

    Edge cases
    • Empty middleware tuple → no middleware applied (direct httpx call).
    • trust_store=None → system CA bundle used by httpx by default.

    @classmethod
def production(
    cls,
    *,
    authority: Any | None = None,
    audience: str = "api",
    retry_policy: Any | None = None,
    trust_store: TrustStore | None = None,
    timeout: float = 30.0,
) -> ClientProfile:
    """
    Production-ready profile.

    Builds middleware stack::

        OTelClientMiddleware → JwtMiddleware (if authority)
        → CorrelationIdMiddleware → RetryMiddleware (if retry_policy)

    Args:
        authority:     ``JwtAuthority`` for signing outbound JWTs.  ``None``
                       means no JWT middleware is added.
        audience:      JWT ``aud`` claim (default ``"api"``).
        retry_policy:  ``RetryPolicy`` for ``RetryMiddleware``.  ``None``
                       means no retry is applied.
        trust_store:   TLS trust config.  ``None`` = system CAs.
        timeout:       Request timeout in seconds.

    Returns:
        Frozen ``ClientProfile`` suitable for production deployments.
    """
    from varco_fastapi.client.middleware import (  # noqa: PLC0415
        CorrelationIdMiddleware,
        JwtMiddleware,
        OTelClientMiddleware,
        RetryMiddleware,
    )

    mw: list[AbstractClientMiddleware] = [
        OTelClientMiddleware(),
        CorrelationIdMiddleware(),
    ]

    if authority is not None:
        mw.append(
            JwtMiddleware(
                authority,
                audience=audience,
                expires_in=3600,
            )
        )

    if retry_policy is not None:
        mw.append(RetryMiddleware(retry_policy))

    return cls(middleware=tuple(mw), trust_store=trust_store, timeout=timeout)

    @classmethod
def from_env(cls) -> ClientProfile:
    """
    Read middleware config from environment variables.

    Env vars::

        VARCO_CLIENT_TIMEOUT       — default timeout in seconds (default: 30)
        VARCO_CLIENT_RETRY_MAX     — max retry attempts (0 = disabled; default: 0)
        VARCO_CLIENT_RETRY_DELAY   — base retry delay in seconds (default: 0.5)
        VARCO_CLIENT_OTEL_ENABLED  — "true"/"false" (default: "true")

    JWT authority is NOT read from env — private keys must be passed explicitly.

    Returns:
        Frozen ``ClientProfile`` configured from environment.

    Edge cases:
        - Unknown env var values → logged and defaults used.
        - ``VARCO_CLIENT_RETRY_MAX=0`` → no retry middleware added.
    """
    from varco_core.resilience import RetryPolicy  # noqa: PLC0415

    from varco_fastapi.client.middleware import (  # noqa: PLC0415
        CorrelationIdMiddleware,
        OTelClientMiddleware,
        RetryMiddleware,
    )

    timeout = float(os.environ.get("VARCO_CLIENT_TIMEOUT", "30"))
    retry_max = int(os.environ.get("VARCO_CLIENT_RETRY_MAX", "0"))
    retry_delay = float(os.environ.get("VARCO_CLIENT_RETRY_DELAY", "0.5"))
    otel_enabled = os.environ.get("VARCO_CLIENT_OTEL_ENABLED", "true").lower() == "true"

    mw: list[AbstractClientMiddleware] = []
    if otel_enabled:
        mw.append(OTelClientMiddleware())
    mw.append(CorrelationIdMiddleware())
    if retry_max > 0:
        mw.append(RetryMiddleware(RetryPolicy(max_attempts=retry_max, base_delay=retry_delay)))

    return cls(middleware=tuple(mw), timeout=timeout)

    AsyncVarcoClient ¶

    AsyncVarcoClient(
    base_url: str | None = None,
    *,
    port: int | None = None,
    verify: bool | str = True,
    config: ClientConfig | None = None,
    configurator: ClientConfigurator[Any] | None = None,
    profile: ClientProfile | None = None,
    middleware: tuple[AbstractClientMiddleware, ...]
    | None = None,
    trust_store: TrustStore | None = None,
    timeout: float | None = None,
)

    Bases: Generic[R]

    HTTP client that mirrors a VarcoRouter's endpoints as typed async methods.

    The metaclass reads the router type R from the generic parameter at class-definition time and generates typed CRUD methods (create, read, update, patch, delete, list) plus methods for any @route-decorated custom endpoints on the router.

    Configuration layers (highest priority first):

    1. Constructor kwargs (base_url, middleware, timeout)
    2. Per-instance configurator kwarg
    3. Class-level _configurator ClassVar
    4. Class-level _profile ClassVar
    5. Defaults (no middleware, system CAs, 30s timeout)

    Usage::

    # Zero-URL instantiation via configurator
class OrderClient(AsyncVarcoClient[OrderRouter]):
    _configurator = OrderConfigurator

async with OrderClient() as client:
    order = await client.create(CreateOrderDTO(name="test"))
    page = await client.list(q="status = 'active'", limit=20)

# Explicit URL
async with AsyncVarcoClient[OrderRouter]("https://api.example.com") as client:
    order = await client.read(order_id)
    Type parameter

    R: VarcoRouter subclass. Resolved at class-definition time.

    Thread safety: ✅ Each instance has its own httpx.AsyncClient. Async safety: ✅ httpx is fully async; concurrent calls are safe within one instance when using async context manager.

    Edge cases
    • No base_url and no configurator → RuntimeError at first request.
    • with_async=True on methods → returns raw dict (JobAcceptedResponse).
    • Pydantic response_model=None (delete) → returns None directly.

    Parameters:

    Name Type Description Default
    base_url str | None

    Explicit base URL. Overrides configurator, config, and env vars.

    		 None
    port int | None

    def __init__(
    self,
    base_url: str | None = None,
    *,
    port: int | None = None,
    verify: bool | str = True,
    config: ClientConfig | None = None,
    configurator: ClientConfigurator[Any] | None = None,
    profile: ClientProfile | None = None,
    middleware: tuple[AbstractClientMiddleware, ...] | None = None,
    trust_store: TrustStore | None = None,
    timeout: float | None = None,
) -> None:
    """
    Args:
        base_url:     Explicit base URL.  Overrides configurator, config, and env vars.
        port:         Optional port number appended to the resolved ``base_url``
                      (e.g. ``port=8080`` turns ``"http://host"`` into
                      ``"http://host:8080"``).
        verify:       TLS verification.  ``True`` = system CAs (default),
                      ``False`` = skip verification, ``str`` = path to CA bundle.
        config:       ``ClientConfig`` bundle.  Explicit kwargs override config fields.
        configurator: Per-instance configurator for URL / proxy / headers.
        profile:      Per-instance profile (middleware / TLS / timeout).
        middleware:   Extra middleware appended to the profile's stack.
        trust_store:  TLS trust config override.
        timeout:      Timeout override in seconds.

    Raises:
        ValueError: When no ``base_url`` can be resolved AND no configurator
                    is attached.  Pass ``base_url=`` or set a class-level
                    ``_configurator`` to avoid this.

    Edge cases:
        - ``base_url`` kwarg wins over ``config.base_url`` when both are given.
        - ``port`` kwarg wins over ``config.port`` when both are given.
        - ``middleware`` tuple is appended to, not replacing, profile middleware.
        - When a ``ClientConfigurator`` is present, URL resolution is deferred
          to it — no ``ValueError`` is raised even if ``base_url`` is None.
    """
    # --- Merge config bundle (lowest priority) then override with explicit kwargs ---
    # config fields act as defaults; any explicit kwarg silently wins over them.
    if config is not None:
        if base_url is None:
            base_url = config.base_url
        if port is None:
            port = config.port
        # verify: explicit kwarg default is True, so only use config when caller
        # did not change it from the default — we distinguish by checking identity
        # against the sentinel default True value.  Since verify=True is also the
        # config default, we just always let an explicit non-default kwarg win.
        # Simplest: if verify is still the default (True) and config sets something,
        # use config.  Otherwise the caller passed an explicit value, keep it.
        if verify is True and config.verify is not True:
            verify = config.verify
        if middleware is None and config.middleware:
            middleware = config.middleware
        if timeout is None and config.timeout != 30.0:
            timeout = config.timeout

    # Resolve configurator: per-instance > class-level
    _cls_configurator_factory = type(self)._configurator
    _configurator = configurator or (
        _cls_configurator_factory() if _cls_configurator_factory else None
    )

    # Resolve base URL: explicit > configurator.get_url()
    if base_url:
        resolved_url: str = base_url
    elif _configurator is not None:
        resolved_url = _configurator.get_url()
    else:
        resolved_url = ""

    # Append port when provided — only when not already embedded in the URL.
    # We check for ":" after the scheme separator to avoid double-appending.
    if port is not None and resolved_url:
        # Strip trailing slash so ":port/" doesn't become "/:port/"
        base_stripped = resolved_url.rstrip("/")
        # Find the host portion (after "://") and check if port is already there
        after_scheme = base_stripped.split("://", 1)[-1]
        if ":" not in after_scheme:
            resolved_url = f"{base_stripped}:{port}"

    self._base_url: str = resolved_url

    # Fail fast: no URL and no configurator means every request will error.
    # Raise here with a helpful message instead of on the first HTTP call.
    if not self._base_url and _configurator is None:
        raise ValueError(
            f"{type(self).__name__}: no base_url configured. "
            "Pass base_url=... to the constructor, provide a ClientConfig with "
            "base_url set, or set a class-level _configurator that implements "
            "get_url() / default_url()."
        )

    # Store verify so _build_httpx_client() can pass it to httpx
    self._verify: bool | str = verify

    # Resolve profile: explicit kwarg > configurator.profile() > class _profile > default
    resolved_profile: ClientProfile
    if profile is not None:
        resolved_profile = profile
    elif _configurator is not None:
        resolved_profile = _configurator.profile()
    elif type(self)._profile is not None:
        resolved_profile = type(self)._profile  # type: ignore[assignment]
    else:
        resolved_profile = ClientProfile()

    # Apply per-instance overrides on top of resolved profile
    if middleware:
        resolved_profile = resolved_profile.with_middleware(*middleware)
    if trust_store is not None:
        resolved_profile = resolved_profile.with_trust_store(trust_store)
    if timeout is not None:
        resolved_profile = resolved_profile.with_timeout(timeout)

    self._resolved_profile = resolved_profile
    self._proxy_url: str | None = _configurator.get_proxy() if _configurator else None

    # httpx.AsyncClient is created lazily (or in __aenter__)
    self._client: httpx.AsyncClient | None = None

    def make_client(
    router_cls: type,
    base_url: str | None = None,
    *,
    port: int | None = None,
    verify: bool | str = True,
    config: ClientConfig | None = None,
    middleware: tuple[AbstractClientMiddleware, ...] = (),
    timeout: float = 30.0,
    profile: ClientProfile | None = None,
) -> AsyncVarcoClient[Any]:
    """
    Factory that creates a typed ``AsyncVarcoClient`` subclass at runtime without
    requiring a ``class MyClient(AsyncVarcoClient[MyRouter]): pass`` declaration.

    The dynamically created class is indistinguishable from a manually declared
    subclass — ``_VarcoClientMeta`` runs normally and injects all CRUD methods.

    DESIGN: runtime class creation via _VarcoClientMeta over manual subclassing
        ✅ One-liner client creation — no boilerplate subclass required
        ✅ ``_VarcoClientMeta`` runs once; generated methods live on the class
        ✅ Returned client is a real ``AsyncVarcoClient`` subclass (isinstance check works)
        ❌ Class name is synthetic (``"{Router}Client"``) — not importable by name

    Args:
        router_cls: The ``VarcoRouter`` subclass that defines the endpoints.
        base_url:   Target service base URL.
        port:       Optional port appended to ``base_url``.
        verify:     TLS verification flag or CA bundle path.
        config:     ``ClientConfig`` bundle (explicit kwargs override config fields).
        middleware: Middleware stack applied to every request.
        timeout:    Request timeout in seconds.
        profile:    ``ClientProfile`` instance (middleware / TLS / timeout bundle).

    Returns:
        A fully configured ``AsyncVarcoClient`` instance with typed CRUD methods
        derived from ``router_cls``.

    Raises:
        ValueError: If no ``base_url`` can be resolved (see ``AsyncVarcoClient.__init__``).

    Example::

        client = make_client(ItemRouter, "https://api.example.com", timeout=5.0)
        items = await client.list()
    """
    # Build a class whose __orig_bases__ looks like AsyncVarcoClient[router_cls]
    # so _VarcoClientMeta._resolve_router_type() picks it up and injects CRUD methods.
    ClientClass = _VarcoClientMeta(
        f"{router_cls.__name__}Client",
        (AsyncVarcoClient,),
        # __orig_bases__ is what Generic machinery stores; the metaclass reads it
        # to find the router type parameter.
        {"__orig_bases__": (AsyncVarcoClient[router_cls],)},  # type: ignore[valid-type]
    )
    # why: ClientClass is a metaclass-constructed type built at runtime
    # (`_VarcoClientMeta(...)` above) — mypy cannot statically prove it is
    # an AsyncVarcoClient[Any] subclass, only its docstring/runtime
    # __orig_bases__ trick does.
    return cast(
        "AsyncVarcoClient[Any]",
        ClientClass(
            base_url,
            port=port,
            verify=verify,
            config=config,
            middleware=middleware or None,
            timeout=timeout if timeout != 30.0 else None,
            profile=profile,
        ),
    )
